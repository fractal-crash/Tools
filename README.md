Auditoria-BloqueosAD
Autor: José Luis Rodríguez García

Script de PowerShell para la identificación de eventos de bloqueo de cuentas Active Directory (EventID 4740), obteniendo usuarios, cantidad de bloqueos, fecha del último incidente y equipos origen.

Versiones
1.0 Versión inicial
1.1 Agrupación automática de usuarios
1.2 Generación de reportes TXT
